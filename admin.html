Portfolio Admin

Connect to your GitHub repo

This admin page edits data.json directly inside your GitHub repo using a Personal Access Token. The token is saved only in this browser's local storage — it is never uploaded anywhere except directly to GitHub's API.

Create a fine-grained token at github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Give it access to only this one repository, with Contents: Read and write permission — nothing else.

Profile

Core details shown in the hero and about section.

Personal Strengths

Short highlight lines shown as a checklist between Skills and Experience.

Achievements

Shown as a bold highlight band under About — a big number/value plus what it means. Keep values short (e.g. "3+", "50K+", "98%").

Work / Projects gallery

Organize your real work into folders (categories) people can browse — e.g. Graphic Design, Motion Video Editing. First upload each image to the assets/ folder in GitHub (an assets/work/ subfolder keeps things tidy), then reference its path here. Leave a folder empty and the site shows a friendly "nothing here yet" placeholder.

Business ventures / links

Add or remove the business pages you want to showcase — e.g. Khalifa, 1% Solution, Sa'ādah. Leave URL blank to show "Link coming soon".

Connect / social links

These show up as icon buttons in your Contact section and footer. Add as many as you like — WhatsApp numbers, Facebook, Instagram, LinkedIn, Telegram, email, Behance, or any other website.
