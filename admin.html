Connect to your GitHub repo

This admin page edits data.json directly inside your GitHub repo using a Personal Access Token. The token is saved only in this browser's local storage — it is never uploaded anywhere except directly to GitHub's API.

Create a fine-grained token at github.com → Settings → Developer settings → Personal access tokens → Fine-grained tokens. Give it access to only this one repository, with Contents: Read and write permission — nothing else.
